## 检查范围

- 从原型抽取通用离线回归，覆盖参数、精度、去重、未知结果、路由、账本分摊和分页异常。
- 对新增演示进行重复回放、并发回放、原交易所归属、净值一致性和临时资源清理验证。
- 检查未注册实盘或凭据接口、跨站回放被拒绝、live 环境启动被拒绝、出站连接与 DNS 被拒绝。
- 对公开候选文件执行敏感文件、令牌特征、个人路径和非示例 IP 地址规则扫描。
- 以独立临时环境运行原型完整回归，原型中含内部事件证据的用例不复制到公开仓库。
- 检查桌面、移动端页面和交互，再将合成演示截图用于 README。
